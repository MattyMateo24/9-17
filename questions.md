In a previous class, there was a homework assignment on implementing the apriori algorithm for a market baskets problem. I wanted to take this assignment and visualize some of the associated groceries, according to the apriori algorithm.


2. How easy or hard was it to actually make this figure? What went smoothly, what
didn’t. How were you able to solve any difficulties?

For the most part, it was easy to generate the picture. The code generated by the AI agent worked well, for the most part. The first issue was that it used the same confidence level that the apriori algorithm used. Although this makes sense in the context of the apriori algorithm, it caused the graph to be unreadable since there were so many associations. I ended up significantly raising the confidence level between groceries on the graph itself, so that only the most prevalant assocations were visible.
